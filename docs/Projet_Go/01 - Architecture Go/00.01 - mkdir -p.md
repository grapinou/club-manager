# mkdir

Créer un dossier.

## Syntaxe

```bash
mkdir nom-du-dossier
```

## Option `-p`

Créer les dossiers parents si nécessaire.

Exemple :

```bash
mkdir -p cmd/server
```

Résultat :

```text
cmd/
└── server/
```

### Avantages

- crée les dossiers intermédiaires automatiquement ;
- ne renvoie pas d'erreur si le dossier existe déjà.

C'est l'option la plus utilisée pour créer une arborescence de projet.

### Sans `-p`

Si tu exécutes :

```
mkdir cmd/server
```

et que le dossier `cmd` n'existe pas, tu obtiendras une erreur :

```
mkdir: impossible de créer le répertoire « cmd/server » : Aucun fichier ou dossier de ce type
```

Car `mkdir` ne crée que le dernier niveau (`server`) et suppose que `cmd` existe déjà.
