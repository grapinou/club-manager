---

`tar -tzf fichier.tar.gz`


tar → outil de gestion d'archives (.tar)

t → list : afficher le contenu de l'archive

z → l'archive est compressée avec gzip (.gz)

f → indique que l'on fournit un fichier

head → n'affiche que les premières lignes

Donc :

tar -tzf archive.tar.gz | head

signifie :

"Affiche les premières lignes du contenu de cette archive compressée."

Le résultat :

go/
go/CONTRIBUTING.md
go/LICENSE
go/PATENTS
go/README.md
...
est rassurant. L'archive contient bien un dossier racine go/, ce qui est exactement ce qu'attend l'installation officielle.

Autre possibilité : 

x	extract	Extraire le contenu de l'archive
z	gzip	Indiquer que l'archive est compressée avec gzip
f	file	Indiquer que le fichier archive est fourni juste après

Donc :

tar -xzf archive.tar.gz
se lit :

"Extrais (x) cette archive compressée gzip (z) à partir du fichier (f) indiqué."
