## `wget` : définition

`wget` signifie **"Web Get"**. C'est un programme en ligne de commande qui permet de **télécharger des fichiers depuis Internet**.


### `curl`

Une autre commande très utilisée est :

```
curl -O https://go.dev/dl/go1.25.0.linux-amd64.tar.gz
```

Elle fait quasiment la même chose.

La différence historique :

- `wget` → pensé principalement pour **télécharger des fichiers**
- `curl` → pensé pour **échanger des données avec des serveurs** (API, HTTP, tests...)

Aujourd'hui, les deux savent faire beaucoup de choses.
