## Définition

`io.Writer` est une interface de la bibliothèque standard de Go.

Elle représente un objet capable de recevoir des données.

Autrement dit :

> Si un objet sait écrire des données, il peut être utilisé comme un `io.Writer`.

---

# La méthode de l'interface

L'interface `io.Writer` ne contient qu'une seule méthode :

```go
type Writer interface {
    Write(p []byte) (n int, err error)
}
```

Tout type qui possède cette méthode implémente automatiquement `io.Writer`.

---

# Pourquoi est-ce utile ?

Certaines fonctions n'ont pas besoin de connaître le type exact de l'objet.

Elles veulent simplement pouvoir écrire des données.

Par exemple :

```go
fmt.Fprintln(w, "Bonjour")
```

`fmt.Fprintln()` attend un `io.Writer`.

Peu importe que `w` soit :

- un fichier ;
- un `http.ResponseWriter` ;
- un buffer mémoire.

Il suffit que l'objet implémente `io.Writer`.

---

# Dans un Handler HTTP

```go
func HomeHandler(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintln(w, "Bienvenue sur Club Manager")
}
```

`w` est un `http.ResponseWriter`.

Cette interface implémente également `io.Writer`.

C'est pourquoi `fmt.Fprintln()` peut écrire directement dans `w`.

---

# Une analogie

Imagine un stylo.

Peu importe que tu écrives sur :

- une feuille ;
- un cahier ;
- une carte postale.

Le stylo sait seulement écrire.

`fmt.Fprintln()` est le stylo.

`io.Writer` représente n'importe quel support sur lequel on peut écrire.

---

# À retenir

- `io.Writer` est une interface.
- Elle représente un objet capable de recevoir des données.
- Tout type qui possède la méthode `Write()` implémente `io.Writer`.
- `fmt.Fprintln()` écrit dans un `io.Writer`.
- `http.ResponseWriter` implémente `io.Writer`.
