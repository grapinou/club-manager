# Go — Les verbes de formatage avec `fmt`

## Objectif

Comprendre les symboles comme :

```text
%v
%s
%d
%q
%w
```

Ces symboles sont appelés des **verbes de formatage**.

Ils indiquent à Go comment une valeur doit être représentée dans un texte.

---

## 1. Les fonctions utilisant un format

Les verbes de formatage sont utilisés avec les fonctions dont le nom se termine généralement par `f`.

Exemples :

```go
fmt.Printf(...)
fmt.Sprintf(...)
fmt.Errorf(...)
log.Printf(...)
log.Fatalf(...)
```

Le `f` signifie ici que la fonction reçoit une chaîne de formatage.

Exemple :

```go
name := "Alice"
age := 28

fmt.Printf("%s a %d ans\n", name, age)
```

Résultat :

```text
Alice a 28 ans
```

Chaque verbe correspond, dans l’ordre, à une valeur située après la chaîne :

```go
fmt.Printf("%s a %d ans\n", name, age)
//          │    │          │     │
//          │    └──────────┼─────┘
//          └───────────────┘
```

- `%s` utilise `name` ;
    
- `%d` utilise `age`.
    

---

## 2. `%v` — valeur par défaut

`%v` signifie :

> Afficher la valeur avec son format par défaut.

```go
name := "Alice"
age := 28
active := true

fmt.Printf("nom : %v\n", name)
fmt.Printf("âge : %v\n", age)
fmt.Printf("actif : %v\n", active)
```

Résultat :

```text
nom : Alice
âge : 28
actif : true
```

`%v` fonctionne avec presque tous les types.

Il est particulièrement pratique lorsqu’on ne veut pas choisir un format spécialisé.

### Avec une erreur

```go
log.Printf("erreur obtenue : %v", err)
```

C’est le format habituel pour afficher une erreur dans un log.

---

## 3. `%+v` — valeur détaillée d’une structure

Avec une structure, `%v` affiche les valeurs :

```go
type Member struct {
	Name string
	Age  int
}

member := Member{
	Name: "Alice",
	Age:  28,
}

fmt.Printf("%v\n", member)
```

Résultat :

```text
{Alice 28}
```

Avec `%+v`, les noms des champs sont également affichés :

```go
fmt.Printf("%+v\n", member)
```

Résultat :

```text
{Name:Alice Age:28}
```

`%+v` est donc utile pour inspecter rapidement une structure pendant le développement.

---

## 4. `%#v` — représentation en syntaxe Go

`%#v` affiche une représentation proche de la syntaxe Go.

```go
fmt.Printf("%#v\n", member)
```

Résultat possible :

```text
main.Member{Name:"Alice", Age:28}
```

Ce format est surtout utile pour :

- le débogage ;
    
- comprendre le type exact d’une valeur ;
    
- examiner une structure complexe.
    

La documentation de `fmt` définit `%#v` comme une représentation de la valeur en syntaxe Go.

---

## 5. `%T` — type de la valeur

`%T` affiche le type d’une variable.

```go
name := "Alice"
age := 28

fmt.Printf("%T\n", name)
fmt.Printf("%T\n", age)
```

Résultat :

```text
string
int
```

Avec une structure :

```go
fmt.Printf("%T\n", member)
```

Résultat possible :

```text
main.Member
```

C’est utile lorsque le type réel d’une valeur n’est pas évident, notamment avec les interfaces.

---

## 6. `%s` — chaîne de caractères

`%s` affiche une chaîne de caractères sans guillemets.

```go
name := "Alice"

fmt.Printf("nom : %s\n", name)
```

Résultat :

```text
nom : Alice
```

`%s` est plus précis que `%v` lorsque l’on sait que la valeur est une chaîne.

---

## 7. `%q` — chaîne entre guillemets

`%q` affiche une chaîne entre guillemets en échappant les caractères spéciaux selon la syntaxe Go.

```go
name := "Alice"

fmt.Printf("nom : %q\n", name)
```

Résultat :

```text
nom : "Alice"
```

Ce format est très utile pour voir les espaces ou caractères invisibles.

```go
value := " Alice\n"

fmt.Printf("valeur : %q\n", value)
```

Résultat :

```text
valeur : " Alice\n"
```

Avec `%s`, l’espace initial et le retour à la ligne auraient été plus difficiles à repérer.

### Exemple avec un chemin de fichier

```go
log.Printf("fichier de configuration utilisé : %q", path)
```

Résultat :

```text
2026/08/06 00:11:00 fichier de configuration utilisé : "config.json"
```

Les guillemets permettent de distinguer clairement la valeur du reste du message.

---

## 8. `%d` — entier en base décimale

`%d` sert à afficher un entier en notation décimale.

```go
port := 8080

fmt.Printf("port : %d\n", port)
```

Résultat :

```text
port : 8080
```

Il peut être utilisé avec les différents types entiers :

```go
int
int8
int16
int32
int64
uint
```

---

## 9. `%f` — nombre décimal

`%f` affiche un nombre à virgule flottante.

```go
price := 12.5

fmt.Printf("prix : %f\n", price)
```

Résultat :

```text
prix : 12.500000
```

Pour limiter le nombre de chiffres après la virgule :

```go
fmt.Printf("prix : %.2f €\n", price)
```

Résultat :

```text
prix : 12.50 €
```

Dans `%.2f` :

- `f` demande un nombre décimal ;
    
- `.2` demande deux chiffres après la virgule.
    

---

## 10. `%t` — booléen

`%t` affiche un booléen.

```go
active := true

fmt.Printf("actif : %t\n", active)
```

Résultat :

```text
actif : true
```

---

## 11. `%p` — adresse mémoire

`%p` affiche une adresse mémoire.

```go
member := Member{Name: "Alice"}

fmt.Printf("adresse : %p\n", &member)
```

Résultat possible :

```text
adresse : 0xc000010120
```

Ce format est surtout utile pour comprendre ou déboguer les pointeurs.

L’adresse exacte peut changer à chaque exécution.

---

## 12. `%w` — envelopper une erreur

`%w` est un cas particulier.

Il ne sert pas seulement à afficher une erreur : il permet de **conserver l’erreur d’origine à l’intérieur d’une nouvelle erreur**.

Il s’utilise avec `fmt.Errorf`.

```go
cfg, err := loadFile()
if err != nil {
	return nil, fmt.Errorf("chargement de la configuration : %w", err)
}
```

On ajoute ici du contexte :

```text
chargement de la configuration
```

tout en conservant l’erreur initiale dans la nouvelle erreur.

C’est ce que l’on appelle **envelopper une erreur**, ou _wrap an error_.

---

## 13. Différence entre `%v` et `%w` pour une erreur

### Avec `%v`

```go
return fmt.Errorf("chargement de la configuration : %v", err)
```

Le texte de l’erreur d’origine est ajouté au message, mais la relation entre les deux erreurs n’est pas conservée.

### Avec `%w`

```go
return fmt.Errorf("chargement de la configuration : %w", err)
```

Le texte est ajouté et l’erreur d’origine reste accessible.

On peut ensuite utiliser :

```go
errors.Is(err, target)
errors.As(err, &target)
errors.Unwrap(err)
```

Les fonctions `errors.Is` et `errors.As` peuvent parcourir les erreurs enveloppées pour retrouver une erreur précise.

---

## 14. Exemple avec `errors.Is`

```go
file, err := os.Open("config.json")
if err != nil {
	return fmt.Errorf("ouverture de la configuration : %w", err)
}
```

Plus haut dans le programme :

```go
if errors.Is(err, os.ErrNotExist) {
	log.Println("le fichier de configuration n'existe pas")
}
```

Même si l’erreur possède maintenant le contexte :

```text
ouverture de la configuration
```

Go peut encore reconnaître l’erreur d’origine `os.ErrNotExist`.

---

## 15. Où utiliser `%w` ?

`%w` s’utilise pour construire et retourner une erreur :

```go
return fmt.Errorf("lecture du fichier %q : %w", path, err)
```

Il ne doit pas être utilisé pour simplement écrire l’erreur dans un log.

Pour un log, on utilise `%v` :

```go
log.Printf("impossible de lire le fichier : %v", err)
```

Pour retourner une erreur enrichie, on utilise `%w` :

```go
return fmt.Errorf("lecture de la configuration : %w", err)
```

Règle simple :

```text
Afficher une erreur → %v
Retourner une erreur en conservant sa cause → %w
```

---

## 16. Combiner plusieurs verbes

Il est possible d’utiliser plusieurs verbes dans le même message :

```go
return fmt.Errorf(
	"lecture du fichier %q pour le club %q : %w",
	path,
	clubName,
	err,
)
```

Exemple de message final :

```text
lecture du fichier "config.json" pour le club "Budokan Sud Oise" : fichier introuvable
```

Ici :

- le premier `%q` reçoit `path` ;
    
- le deuxième `%q` reçoit `clubName` ;
    
- `%w` reçoit `err`.
    

L’ordre des valeurs doit correspondre à l’ordre des verbes.

---

## 17. Le caractère `\n`

Dans une chaîne, `\n` représente un retour à la ligne.

```go
fmt.Printf("première ligne\nseconde ligne\n")
```

Résultat :

```text
première ligne
seconde ligne
```

`fmt.Printf` n’ajoute pas automatiquement de retour à la ligne.

Il faut donc souvent terminer le format par `\n` :

```go
fmt.Printf("nom : %s\n", name)
```

En revanche, les fonctions `Println` ajoutent automatiquement une fin de ligne :

```go
fmt.Println("nom :", name)
log.Println("nom :", name)
```

## 18. Tableau récapitulatif

|Verbe|Utilisation|Exemple|
|---|---|---|
|`%v`|Valeur au format par défaut|`Alice`, `28`, `true`|
|`%+v`|Valeur détaillée, notamment pour une structure|`{Name:Alice Age:28}`|
|`%#v`|Représentation en syntaxe Go|`main.Member{Name:"Alice"}`|
|`%T`|Type de la valeur|`string`, `int`, `main.Member`|
|`%s`|Chaîne sans guillemets|`Alice`|
|`%q`|Chaîne entre guillemets et échappée|`"Alice"`|
|`%d`|Entier décimal|`8080`|
|`%f`|Nombre à virgule flottante|`12.500000`|
|`%.2f`|Nombre avec deux décimales|`12.50`|
|`%t`|Booléen|`true`|
|`%p`|Adresse mémoire|`0xc000010120`|
|`%w`|Erreur enveloppée avec `fmt.Errorf`|conserve l’erreur d’origine|
|`%%`|Afficher le caractère `%`|`50%`|

## 19. Exemple appliqué à Club Manager

```go
func main() {
	cfg, err := config.Load("config.json")
	if err != nil {
		log.Fatalf(
			"impossible de charger la configuration : %v",
			err,
		)
	}

	log.Printf("configuration chargée pour le club %q", cfg.ClubName)
}
```

Dans cet exemple :

- `%v` affiche l’erreur dans le journal ;
    
- `%q` affiche le nom du club entre guillemets.
    

Dans la fonction `Load`, on pourrait enrichir une erreur :

```go
func Load() (*Config, error) {
	data, err := os.ReadFile("config.json")
	if err != nil {
		return nil, fmt.Errorf(
			"lecture du fichier %q : %w",
			"config.json",
			err,
		)
	}

	// ...

	return cfg, nil
}
```

Ici :

- `%q` rend le nom du fichier clairement visible ;
    
- `%w` conserve l’erreur renvoyée par `os.ReadFile`.
    

---

## Comprendre et retenir

Les verbes de formatage décrivent la manière dont une valeur doit être représentée.

Les plus utiles au quotidien sont :

```text
%v  → valeur générique
%s  → chaîne
%q  → chaîne entre guillemets
%d  → entier
%f  → nombre décimal
%t  → booléen
%T  → type
%w  → erreur enveloppée avec fmt.Errorf
```

Pour les erreurs :

```text
Dans un log       → %v
Dans fmt.Errorf   → généralement %w
```

Exemple typique :

```go
return fmt.Errorf("lecture du fichier %q : %w", path, err)
```

Cette ligne apporte du contexte sans perdre l’erreur d’origine.
