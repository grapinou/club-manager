## Workflow

Le workflow représente le cycle classique de travail :

Modifier → Vérifier → Ajouter → Commit → Envoyer

### Commandes principales

- [[01 - git status]]
	  Vérifier l'état du dépôt

- [[02 - git add]]
	  Ajouter des fichiers à l'index
		  Je choisis ce que je veux enregistrer.

- [[03 - git commit]]
	  Créer un point de sauvegarde
		  J'enregistre ces modifications dans mon historique local.

- [[04 - git push]]
	  Envoyer les commits vers le dépôt distant
		  Je partage cet historique avec GitHub.

## Historique

Ces commandes permettent de comprendre ce qui s'est passé dans le projet.

### Commandes principales

- [[05 - git diff]]
  Voir les modifications avant commit

- [[06 - git log]]
  Consulter l'historique des commits
