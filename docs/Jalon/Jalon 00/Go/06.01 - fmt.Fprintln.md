## Définition

`fmt.Fprintln()` écrit du texte dans un objet capable de recevoir des données.

Sa signature est :

```go
func Fprintln(w io.Writer, a ...any) (n int, err error)
```


Elle appartient au package :

```go
import "fmt"
```

---

# Décomposition de la fonction

```go
fmt.Fprintln(w, "Bonjour")
```

- `fmt` → package contenant les fonctions de formatage.
- `Fprintln` → écrit une ligne dans un objet.
- `w` → destination de l'écriture.
- `"Bonjour"` → texte à écrire.

---

# Pourquoi le F ?

Le nom de la fonction suit une convention du package `fmt`.

| Fonction | Destination |
|----------|-------------|
| `Println()` | La sortie standard (le terminal). |
| `Fprintln()` | Un objet fourni en argument. |
| `Sprintln()` | Une chaîne de caractères. |

Concernant la dénomination :

|Fonction|Lettre|Destination|
|---|---|---|
|`Println()`|_(aucune)_|La sortie standard (le terminal)|
|`Fprintln()`|**F = File**|Un objet qui implémente `io.Writer`|
|`Sprintln()`|**S = String**|Une chaîne de caractères|

Exemple :

```go
fmt.Println("Bonjour")
```

Affiche :

```
Bonjour
```

dans le terminal.

---

```go
fmt.Fprintln(w, "Bonjour")
```

Envoie :

```
Bonjour
```

dans `w`.

---

```go
texte := fmt.Sprintln("Bonjour")
```

La variable `texte` contient :

```
Bonjour
```

---

# Pourquoi peut-on écrire dans `w` ?

Le paramètre de `Fprintln()` est :

```go
io.Writer
```

`io.Writer` est une interface.

Elle décrit un objet capable de recevoir des données.

Le `http.ResponseWriter` que nous recevons dans un Handler implémente cette interface.

Autrement dit :

```
http.ResponseWriter
        │
        ▼
implémente
        │
        ▼
io.Writer
```

C'est pourquoi cette ligne fonctionne :

```go
fmt.Fprintln(w, "Bienvenue sur Club Manager")
```

`fmt` sait uniquement que `w` est capable de recevoir des données.

Il n'a pas besoin de connaître le navigateur ni le protocole HTTP.

---

# Que fait réellement Fprintln() ?

Lorsque l'on écrit :

```go
fmt.Fprintln(w, "Bienvenue")
```

Go :

1. transforme les données en texte ;
2. ajoute automatiquement un retour à la ligne (`\n`) ;
3. écrit le résultat dans `w`.

Le navigateur reçoit alors :

```
Bienvenue
```

---

# Pourquoi ajouter un retour à la ligne ?

Le suffixe :

```
ln
```

signifie :

> **line**

Autrement dit :

```go
fmt.Fprintln(...)
```

ajoute automatiquement :

```
\n
```

à la fin.

À l'inverse :

```go
fmt.Fprint(...)
```

n'ajoute aucun retour à la ligne.

---

# Les valeurs de retour

`Fprintln()` renvoie :

```go
n, err := fmt.Fprintln(w, "Bonjour")
```

- `n` → nombre d'octets écrits.
- `err` → erreur éventuelle.

Dans les Handlers simples, ces valeurs sont souvent ignorées.

---

# Exemples

Écrire dans le navigateur :

```go
func HomeHandler(w http.ResponseWriter, r *http.Request) {
	fmt.Fprintln(w, "Bienvenue sur Club Manager")
}
```

Écrire dans le terminal :

```go
fmt.Println("Serveur démarré")
```

Créer une chaîne :

```go
message := fmt.Sprintln("Bonjour")
```

---

# À retenir

- `fmt.Fprintln()` écrit dans un objet.
- Cet objet doit implémenter l'interface `io.Writer`.
- `http.ResponseWriter` implémente `io.Writer`.
- `Fprintln()` ajoute automatiquement un retour à la ligne.
- Le package `fmt` ne sait pas où il écrit : il sait seulement que l'objet est capable de recevoir des données.
