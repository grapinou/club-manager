# http.ServeMux

## Définition

`http.ServeMux` est le routeur fourni par la bibliothèque standard de Go.

Il appartient au package :

```go
import "net/http"
```

Son rôle est d'associer des routes HTTP à des Handlers.

---

# Création d'un ServeMux

Un nouveau routeur est créé avec :

```go
mux := http.NewServeMux()
```

Le routeur est initialement vide.

Les routes sont ensuite ajoutées une par une.

---

# Ajouter une route

Exemple :

```go
mux.HandleFunc("/", handlers.HomeHandler)

mux.HandleFunc("/contact", handlers.ContactHandler)
```

Le `ServeMux` mémorise l'association entre une URL et un Handler.

---

# Utilisation

Une fois configuré, le routeur est passé au serveur HTTP :

```go
http.ListenAndServe(":8080", mux)
```

À chaque requête, Go demande au `ServeMux` quel Handler doit être exécuté.

---

# Le routeur par défaut

Lorsque l'on écrit :

```go
http.HandleFunc("/", handlers.HomeHandler)
```

la route est ajoutée au **routeur global** fourni par Go.

Lorsque l'on écrit :

```go
http.ListenAndServe(":8080", nil)
```

`nil` signifie :

> Utiliser le `DefaultServeMux`.

Autrement dit, un `ServeMux` existe déjà en arrière-plan.

---

# Pourquoi créer son propre ServeMux ?

Créer son propre `ServeMux` permet :

- d'éviter d'utiliser le routeur global ;
- de mieux organiser le projet ;
- de centraliser la configuration des routes ;
- de rendre le code plus explicite.

Exemple :

```go
func New() *http.ServeMux {

	mux := http.NewServeMux()

	// configuration des routes

	return mux
}
```

---

# ServeMux et les interfaces

`ServeMux` possède une méthode :

```go
ServeHTTP(w http.ResponseWriter, r *http.Request)
```

Grâce à cette méthode, il implémente automatiquement l'interface :

```go
http.Handler
```

C'est pourquoi cette ligne fonctionne :

```go
http.ListenAndServe(":8080", mux)
```

`ListenAndServe()` attend un `http.Handler`, et `*http.ServeMux` respecte ce contrat.

---

# À retenir

- `ServeMux` est le routeur de la bibliothèque standard.
- Il associe des routes à des Handlers.
- `http.NewServeMux()` crée un nouveau routeur.
- `nil` utilise le `DefaultServeMux`.
- `ServeMux` implémente l'interface `http.Handler`.
