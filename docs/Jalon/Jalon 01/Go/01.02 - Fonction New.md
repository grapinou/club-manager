# La fonction `New`

## Définition

`New` est une fonction très utilisée en Go.

Elle sert généralement à créer et initialiser une nouvelle valeur.

Exemple :

```go
func New() *http.ServeMux {
	return http.NewServeMux()
}
```

---

# Une convention, pas un mot-clé

Contrairement à certains langages, `New` n'est **pas** un mot réservé du langage Go.

C'est simplement une fonction dont le nom suit une convention largement utilisée.

On pourrait écrire :

```go
func CreateRouter() *http.ServeMux {

}
```

ou

```go
func BuildRouter() *http.ServeMux {

}
```

Le programme fonctionnerait également.

Cependant, la convention en Go est d'utiliser le nom :

```go
New()
```

lorsqu'une fonction construit un nouvel objet.

---

# Pourquoi utiliser `New` ?

Le nom indique immédiatement au lecteur :

> Cette fonction crée une nouvelle valeur.

Le code est plus facile à comprendre.

Exemple :

```go
router := router.New()
```

On comprend immédiatement que l'on obtient un nouveau routeur.

---

# Exemple dans notre projet

Dans le package `router` :

```go
package router

import "net/http"

func New() *http.ServeMux {
	return http.NewServeMux()
}
```

Cette fonction crée un nouveau `ServeMux` et le retourne.

---

# D'autres exemples dans la bibliothèque standard

La bibliothèque standard utilise très souvent cette convention.

Par exemple :

Créer un routeur :

```go
http.NewServeMux()
```

Créer un buffer :

```go
bytes.NewBuffer(...)
```

Créer un logger :

```go
log.New(...)
```

Créer un template :

```go
template.New(...)
```

---

# Une fonction comme les autres

`New` reste une fonction classique.

Elle peut :

- recevoir des paramètres ;
- retourner une valeur ;
- être appelée comme n'importe quelle autre fonction.

Exemple :

```go
router := router.New()
```

---

# Pourquoi retourne-t-elle souvent un pointeur ?

Les fonctions `New` retournent très souvent un pointeur.

Exemple :

```go
func New() *http.ServeMux
```

Cela permet de manipuler le même objet sans effectuer de copies inutiles.

C'est une pratique très courante en Go.

---

# À retenir

- `New` est une convention de nommage.
- Ce n'est pas un mot-clé du langage Go.
- Une fonction `New` crée généralement une nouvelle valeur.
- Elle retourne souvent un pointeur vers cette valeur.
- La bibliothèque standard utilise largement cette convention.
